# 开源模型清单（全部 CC0，来自 Poly Haven，1K 贴图 glTF）

| 文件夹 | 面数 | 用途建议 |
|---|---|---|
| `shrub_02/` | 5.2 万 | 灌木丛（躲藏区）：近景用原模型，远处用 LOD 简化或换成面片 |
| `shrub_03/` | 1.7 万 | 灌木丛主力（面数最低，实例化最划算） |
| `shrub_04/` | 4.8 万 | 灌木丛点缀 |
| `fern_02/` | 6 千 | 树下、驳岸边的地被 |
| `rock_07/`、`rock_09/` | 2–3 万 | 驳岸边、湖心岛的假山石 |
| `rock_moss_set_01/`、`rock_moss_set_02/` | 6 万 | 成组的带苔藓石块，湖心岛岸边 |
| `stone_01/` | 7 万 | 散落的小石块 |
| `boulder_01/` | 12 万 | 大块假山石，**全场最多放 3–4 块** |
| `street_lamp_02/` | 2 万 | 湖边步道路灯，每 25 米一盏 |
| `painted_wooden_bench/` | 630 | 湖边长椅（颜色可改成深绿或朱红） |

**树木不用下载模型**：Poly Haven 的树每棵几百万面，浏览器跑不动。项目里已有的 ez-tree 自带 Oak、Pine、Ash、Aspen、Bush 预设和树皮 / 树叶贴图（node_modules/@dgreenheck/ez-tree/src/lib/assets/，其中还有 willow 树皮），用它生成树即可。

来源：https://polyhaven.com/models （CC0，可商用，无需署名，但建议在"关于"页致谢 Poly Haven）。
